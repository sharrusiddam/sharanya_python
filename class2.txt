id():
=====
It is a predefine function in python.The main objective of id() function is know the
address of a variable where our value is stored at memory allocation.

Ex1:
===
import time 
age=21
print(age)
print()
print(id(age))
print()
time.sleep(2)
print('End of an application')


Ex2:
===
import time 
age=21
print("Age is:",age)
print()
print("Address of age is:",id(age))
print()
time.sleep(2)
print('End of an application')


type():
======
It is a predefine function in python.The main objective of type() function is to 
know the what type of data type we are using while writing business logic.


Ex1:
===
import time 
Eid=1001 
print('Employee id is:',Eid)
print()
print("Address is:",id(Eid))
print()
print("Data type is:",type(Eid))  #<class 'int'>
print()
time.sleep(2)
print("End of an application")




An identifier(variable):
=======================


What is an identifier(variable)?
---------------------------------
It is a name inside the python script or python module or python program.


Rule1:
=====
Only allow characters A-Z or a-z or number or decimal number from 0-9 and 
only one specail character(_).

Specail characters are:$,#,space,_,@,&


Ex1:
===
import time 
ABC_abc_12345=1200 
print("The value is:",ABC_abc_12345)
print()
print("The address is:",id(ABC_abc_12345))
print()
print("The data type is:",type(ABC_abc_12345))
print()
time.sleep(2)
print("End of an application")
